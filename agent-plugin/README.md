# ARCHMAGE Agent Plugin template

This directory contains the portable Agent Plugins 1.0.0 manifests. It is a build template, not a
standalone installation: `scripts/build_agent_plugin.py` adds the Agent Skill, policy manifest,
license, and self-contained Python runtime to the release archive.

The plugin is an interoperability adapter around ARCHMAGE's authoritative Python enforcement
runtime. It does not replace that runtime or create a second policy implementation.
